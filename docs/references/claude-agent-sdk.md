## 本项目的用法（T9）

- 每轮新建一个 `ClaudeSDKClient`，`resume=会话的 sdk_ref`；`TurnEnd.resume_ref` 是 result 的 `session_id`。
- **认证**：模型配置 `api_key_env` 有值 → 注入 `ANTHROPIC_API_KEY`，`ANTHROPIC_AUTH_TOKEN` 置空，`CLAUDE_CONFIG_DIR=<data_dir>/claude`；变量缺失 → 本轮 `failed`（不启动 CLI）。两种模式都先把继承来的宿主变量置空（`HOST_BLANKED_ENV` + `HOST_BLANKED_PREFIXES`：OAuth token/scope、provider 开关、模型覆盖、宿主会话/消息/桌面版标记），`ANTHROPIC_BASE_URL` 取模型配置的 `base_url`，没有配置时换成 `https://api.anthropic.com`；`CLAUDE_CONFIG_DIR` 在登录模式下保持继承值。`api_key_env` 为空 → 本机登录模式：`ANTHROPIC_API_KEY`、`ANTHROPIC_AUTH_TOKEN` 置空，不改 `CLAUDE_CONFIG_DIR`（会话存储留在 `~/.claude/projects/`），`Usage.auth="login"`，成本不强制。R4：登录模式已实测（默认位置 + 恢复正常）；API key 模式待有 key 后由 `make smoke` 验证。
- **成本**：每轮的花费 = 本次 `total_cost_usd` − 该会话上次记录的累计值，记录落盘在 `<data_dir>/claude/studio-cost-ledger/<session_id>.json`（进程重启后仍能求差）。本次累计值小于记录值（transcript 没保存累计值、`/clear` 等）时，把本次累计值当作本轮花费；累计值为 0 时不更新记录。token 数直接用 result 的 `usage`（每轮值；输入 = `input_tokens` + 两种 cache token）。
- **预算**：步数（工具调用数）超限 → `interrupt()`，本轮 `budget_exceeded`；成本上限在 API key 模式下交给 `max_budget_usd`（正好是本轮花费），result 为 `error_max_budget_usd` 时本轮 `budget_exceeded`；登录模式不设。
- **工具名**：原生工具名原样保留（`Write`/`Edit`/`MultiEdit`/`NotebookEdit`/`Bash` 已加入 `events.FILE_TOOL_NAMES`）；业务工具去掉 `mcp__studio__` 前缀后作为 `ToolCall.name`。
- **密钥与读取范围（2026-09-28，M1 最终审查 I5）**：`build_env` 另外把继承来的、名字按下划线分段匹配 `KEY`/`API_KEY`/`TOKEN`/`SECRET`/`PASSWORD`/`PASSWD` 的变量一律置空（大小写不敏感；`OPENAI_API_KEY`、`DEEPSEEK_API_KEY`、模型配置的 `api_key_env` 本身都在内，不误伤 `SSH_AUTH_SOCK`、`KEYCHAIN_*`），API key 模式下随后只重新写入 `ANTHROPIC_API_KEY`。SDK 把 `options.env` 合并在 `os.environ` 之上（`subprocess_cli.py` 的 `process_env`），所以置空对 CLI 及其 Bash 子进程都生效。另加一个 `PreToolUse` hook（matcher `Read|Glob|Grep`）：Read 的 `file_path`、Glob/Grep 的 `path` 在解析 `..` 和符号链接后必须落在工作区内（含 `upstream/`），Glob 的 `pattern`、Grep 的 `glob` 不能是绝对路径、`~` 开头或含 `..`。
- **剩余风险（已知，未处理，登记在 tech-debt）**：① `allow_web` 打开时 WebFetch/WebSearch 放行所有域名，agent 能把它读到的任何内容放进 URL 外发；② SDK sandbox 只作用于 Bash，而且默认**不限制读**——Bash 仍能 `cat` 工作区外的文件（例如 `backend/.env`），Bash 本身没有外网，但读到的内容可以经 ① 外发；③ 置空只覆盖"名字像密钥"的变量，值是密钥但名字不像的变量不受影响。可能的对策：sandbox `filesystem.denyRead` 拒读仓库与 `data/`、WebFetch 加域名白名单或按阶段关闭联网。
