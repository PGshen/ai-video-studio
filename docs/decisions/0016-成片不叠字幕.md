# 0016：成片不叠字幕

## 元信息

| 项 | 值 |
|---|---|
| 状态 | 已采纳 |

| 相关 | [ADR 0015 成片整体渲染](0015-成片整体渲染.md)、[设计 §5.3/§10](../design/2026-09-26-architecture.md)、M2 计划 D15/D17 |

## 背景

M2 的 worker 在成片里把每个镜头的完整旁白烧成字幕（Pillow 画透明 PNG + ffmpeg `overlay`）。实际成片里，字幕是整段旁白按固定大字号排版，常占满画面下半部，和动画自带的文字、图表标注叠在一起，画面很乱。动画代码本身已经承担画面上的文字表达，旁白字幕是重复且不可控的一层。

## 决定

- worker 不再叠加字幕：渲染出的整条视频直接作为 `output/final.mp4`（复制，不再经过 ffmpeg 重编码）。
- 删除 `_burn_subtitles`、字幕 PNG 绘制、字体查找和 `_run_subprocess`；同时删除 ADR 0015 为字幕区间引入的镜头结束标记（`SCENE_END_MARKER`/`parse_scene_durations`）、缓存旁的时长元数据，缓存回到只有 `<hash>.mp4`。ADR 0015 其余决定不变。
- 动画阶段的代码生成本来就没有字幕概念，无需改提示词。

## 考虑过的其他方案

- **保留字幕但缩小/做成开关**：要新增配置和界面，且仍然是整段旁白而不是按句对齐，效果有限。不选；需要字幕时再单独设计按句对齐的方案。

## 影响

- 成片不再有旁白字幕；`final.mp4` 就是 Manim 的输出。
- 设计文档 §5.3 里"加字幕"一句已不再成立（已批准的设计按红线不直接修改，以本 ADR 为准）。
- `pillow` 仍在 `backend/pyproject.toml` 的依赖里，后端已不再 import；移除它要动依赖与锁文件，留给负责人决定，已记入 tech-debt。
- `references/ffmpeg.md` 里关于字幕叠加、concat 的验证记录保留，作为将来需要时的已验证参考。
