# 0005：成片渲染并入动画阶段

## 元信息

| 项 | 值 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-26 |
| 相关 | [架构设计 §5.3](../design/2026-09-26-architecture.md) |

## 背景

成片渲染是确定性操作，本身没有可以对话的内容。视觉自检已经让单个镜头的渲染成为代码阶段的一部分；看成片发现问题，也本来就要回到代码对话里修改。

## 决定

流程定为：选题打磨 → 叙事 → 动画（代码 + 成片）。动画阶段内由用户触发"渲染成片"（worker 执行，按哈希缓存镜头），满意后"成片定稿"。

## 考虑过的其他方案

- **把渲染作为独立的第四阶段**：不选的原因：多一次跨阶段跳转，也没有可以对话的内容。

## 影响

定稿点变为三个：选题简报、叙事、成片。第一版只实现 manim，保留渲染引擎接口。
