# 0001：新建独立仓库重建系统，只迁移资产

## 背景

旧项目 `../ai-video` 的主干是"批处理加审核闸门"：worker_tasks 轮询、Temporal 编排、一次性生成。改成对话式后，执行模型、状态机、AI 调用抽象、产物版本和前端都要重做。最初考虑在旧仓库的 `studio/` 子目录里开发，但旧仓库根目录的 CLAUDE.md 会被 AI 工具逐级加载，其中的说明和新系统冲突；而且新旧代码大量同名，搜索时容易读错或改错。

## 决定

在同级目录新建独立仓库 `ai-video-studio`。渲染、TTS、校验规则、提示词资产等从旧项目**复制后改写**，新代码不 import 旧代码。旧项目只读。

## 考虑过的其他方案

- **在旧代码上修补**：不选的原因：新旧两条执行路径会长期并存，分叉越来越多。
- **旧仓库内的 `studio/` 子目录**：不选的原因：旧的 CLAUDE.md 会持续误导 AI，还有搜索噪声和记忆混杂的问题。

## 影响

AI 的上下文干净。迁移资产时需要跨目录读取，见 [legacy-assets.md](../references/legacy-assets.md)；`.claude/settings.json` 已把 `../ai-video` 加为额外目录。
