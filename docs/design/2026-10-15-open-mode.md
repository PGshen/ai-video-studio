# 完全自由模式：运行时原生的单阶段项目

状态：待批准（2026-10-15）。本文**新增**第三种项目模式 `open`（界面名「完全自由」），不修改已批准的 [架构设计](2026-09-26-architecture.md)、[自由模式设计](2026-10-12-free-mode.md) 与各子项目设计：多阶段模式、现有自由模式（`free_explainer` / `free_produce`）的行为全部不变。

## 1. 背景与目标

现有自由模式虽然不分阶段，但仍带着格式契约：自由短片必须配乐，镜头要按 `animation/shots.json` + 场景脚本的固定结构写，过程要经过 `validate_scenes_html`、`render_preview_html`，成片由 worker 按固定文件位置渲染；系统提示词里也有大段交付约定。想"像直接用 Claude Code 一样"随手做点东西时，这些都是约束。

**目标**

1. **没有格式约束**：不规定产物结构、文件位置、步骤与检查；agent 用什么技术做视频（HTML + 录屏、ffmpeg、Python、three.js……）自己决定。
2. **初始工作区极简**：只有 `style/`（项目风格）与顶层 `project.md`（主题与风格引用）。
3. **系统提示词不加东西**：使用各运行时自己的默认提示词（Claude 为 Claude Code 默认系统提示词），效果接近在终端里直接用 Claude Code 操作这个目录。
4. **画布只有「文件」**：生成的文件都在文件画布里浏览、编辑与预览（含图片、音频、视频、HTML）。

**不做**：worker 成片、「成片」标签页、定稿前检查；与其他模式互相转换；形态（讲解/短片/MV）区分；除配音外的自建工具。

## 2. 已确认的决定

| 项 | 决定 |
|---|---|
| 实现方式 | 新增 `mode="open"` 与单阶段 `open`（方案 A）；不放宽现有 `free_produce`（方案 B），不脱离阶段系统（方案 C） |
| 系统提示词 | 运行时默认：Claude 用 `claude_code` preset；Codex 用 CLI 自带指令，不追加；OpenAI Agents SDK 的 instructions 为空 |
| 运行时 | 三个都支持 |
| 执行环境 | 保留读写隔离（沙箱照旧），**放开 Bash/Shell 联网**，便于安装依赖、下载素材 |
| 自建工具 | 只给一个通用配音工具 `tts`（密钥在后端，agent 自己做不了）；其余一律不给 |
| 可写范围 | 整个工作区，包括 `style/` 与 `project.md`；只保护 `uploads/` 与系统目录 |
| 完成状态 | 手动「标记完成 / 重新打开」，绑定当前快照，没有前置检查 |
| 画布 | 只有 `FileCanvas`，不显示标签栏；`FileCanvas` 增加 HTML 预览 |
| 依赖目录 | 任意深度的 `node_modules`、`.venv`、`__pycache__` 不进快照与文件树（§4.0） |

## 3. 项目模型

### 3.1 类型

`stages/pipeline.py`：

- `Mode` 增加 `"open"`；`VideoKind` 增加 `"open"`。
- 常量 `OPEN_STAGE = "open"`、`OPEN_KIND = ProjectKind("html", False, "none", "open")`。`open` 项目的 `engine/narration/music_source` 是占位值，只为复用现有数据结构，任何代码都不应据此判断形态；应通过 `mode == "open"` 分支。
- `kind_errors`：`mode == "open"` 时只接受 `OPEN_KIND`（其它组合报"完全自由项目没有形态配置"），并跳过"无旁白必须配乐"等形态规则。
- `video_kind_of`：`mode == "open"` → `"open"`。
- `build_pipeline`：`mode == "open"` → `["open"]`。
- `valid_kinds()` 加入 `OPEN_KIND`；`PRESETS` 加一张卡：「完全自由」——"没有结构和检查，像直接用 Claude Code 一样在工作区里随意创作；产物都在「文件」里预览。"，`music_choices=("none",)`。
- `kind_from_settings`：`mode == "open"` 时直接返回 `OPEN_KIND`（不看形态字段）；缺失/非法照旧按 `staged`。

### 3.2 创建

- `POST /projects`：`mode="open"` 时不要求、也不接受 `engine/narration/music_source`（给了就 422），由服务端填 `OPEN_KIND`。新增可选字段 `theme: str`（主题描述，最长 2000 字）；其它模式忽略它。
- 初始文件：`style/**`（与现状相同的选取规则）+ 顶层 `project.md`，内容：

  ```markdown
  # <标题>

  ## 主题

  <theme；从选题卡创建时为卡片内容（一句话卖点、反直觉点、标签）；都没有时写"（未填写）">

  ## 风格

  项目风格在 `style/`，入口 `style/STYLE.md`（<风格名>）。
  ```

  不生成 `notes/`、`notes/project.md`、`notes/idea-card.md`。
- 音色/语速照旧复制默认值进 `project.settings`（`tts` 工具用）。
- `GET /api/video-kinds` 带上新卡片及可用性（`unavailable_reason` 共用：`open` 阶段未注册时不可用）。`ProjectOut.mode` 可取 `"open"`。

## 4. `open` 阶段

`stages/open/__init__.py`，在 `main` 注册；后端与前端 `STAGE_TITLES` 加 `open: "完全自由"`。

| 属性 | 取值 |
|---|---|
| `system_prompt()` | `None`（见 §5.1） |
| `tools()` | `[TTS_TOOL]`（§4.2） |
| `allow_web` | `True` |
| `exec_network` | `True`（新属性，§5.2） |
| `workspaceless` | `False` |
| `reads()` | `[]` |
| `prepare_turn` | 什么都不做 |
| `artifact_dirs()` | `[]`（新会话前言不列"现有产物"；agent 自己 `ls`） |
| `write_scope()` | 见 §4.1 |
| `status_summary` | `""`（前言没有"当前产物状态"一节） |
| `finalize_blockers` | `[]` |

### 4.0 依赖目录不进快照

agent 可能在工作区里 `npm install` 或建虚拟环境。快照扫描（`workspace/snapshot.py`）与文件树（`workspace/files.py`）目前只排除顶层系统目录，`node_modules/` 会整份进快照库。改为：**任意深度**名为 `node_modules`、`.venv`、`__pycache__` 的目录不参与快照、不列进文件树（新常量 `EXCLUDED_DIR_NAMES`）。这对所有项目生效；多阶段与现有自由模式的工作区不会出现这些目录，所以行为不变。回滚不触碰它们（与 `EXCLUDED_TOP_DIRS` 相同语义）。

上下文前言照旧生成，只会剩下通用的"用户手动修改 / 回滚通知 / 越界还原"三节——它们描述的是系统做过的事，不是约束。

### 4.1 可写范围

`WriteScope(writable=["*"], tool_managed=["upstream/*", "output/*", ".cache/*"])`。`style/`、`project.md` 可写；`uploads/` 由 `is_writable` 统一禁止（ADR 0026）。`tts` 的输出路径由 agent 指定，不进 `tool_managed`。

### 4.2 `tts` 工具

`stages/common/narration/tts.py`，与 `synthesize_tts` 共用底层 TTS 客户端与 `_project_voice_and_speed`，但**不读写叙事格式**：

- 参数：`text`（必填，单段，长度上限同现有单镜头上限）、`out_path`（工作区相对路径，扩展名 `.mp3` 或 `.wav`，须在本阶段可写范围内且不在 `uploads/`）、`voice`（可选，默认项目音色）、`speed`（可选，默认项目语速）。
- 返回：写入路径与时长（秒）。
- 工具描述就是它的完整说明，不进系统提示词。
- `stages={"open"}`。

## 5. 运行时扩展

### 5.1 运行时默认提示词

- 阶段协议 `StageDefinition.system_prompt()` 返回类型改为 `str | None`；`TurnContext.system_prompt` 同步为 `str | None`。`None` 表示"使用运行时默认提示词，不追加任何内容"。现有阶段全部返回 `str`，行为不变。
- `ClaudeRuntime`：`None` → `system_prompt={"type": "preset", "preset": "claude_code"}`。内置工具在 `open` 阶段扩成 Claude Code 常用集合（Read/Write/Edit/MultiEdit/Glob/Grep/Bash/TodoWrite，加上原生联网工具），并通过 `disallowed_tools` 禁掉需要 UI 配合或会改变会话模式的工具（`AskUserQuestion`、`EnterPlanMode`/`ExitPlanMode` 等；最终名单在计划阶段对内置 CLI 实测确定）。写入/读取 hook、轮末 guard 照旧。
- `CodexRuntime`：`None` → `build_args` 不传阶段指令；`prompt_digest(None)` 为固定值，会话中途不会触发 `PROMPT_UPDATE`。
- `OpenAIRuntime`：`None` → `instructions=None`。
- `runner.py` 中三处 `system_prompt=job.stage.system_prompt()` 原样透传。

这是阶段协议与 `TurnContext` 的公共接口变化，写进 ADR 0031。

### 5.2 Bash/Shell 联网

- 阶段协议增加 `exec_network: bool`（现有阶段全部 `False`）；`TurnContext`、`ToolContext` 增加同名字段，由 TurnRunner 从阶段取。
- Claude：`sandbox_settings(..., network=True)` 时加 `network.allowedDomains`，放行全部出站。通配写法（如 `"*"`）需实测；不支持时退回一份常用域名白名单（npm、PyPI、GitHub、jsDelivr/unpkg、Google Fonts 等），写进 `sandbox_paths`。
- OpenAI Shell：`seatbelt_profile(..., network=True)` 去掉 `(deny network*)`。LaunchServices/Apple Event/`open`/`osascript` 三条拒绝规则**保留**（它们防的是借沙箱外进程逃逸，不只是联网）。
- Codex：`workspace-write` 沙箱打开网络访问（配置键在计划阶段对本机 codex 版本实测，写进 `references/codex.md`）。
- 读隔离（拒读仓库、数据目录、凭据目录）与写隔离（只写当前工作区）不变；`exec_mode` 的三种取值与"无隔离执行"开关逻辑不变（`disabled` 时依旧没有 Bash）。

## 6. 完成与重新打开

复用现有通用接口 `POST /projects/{id}/stages/open/finalize` 与 `.../reopen`（`finalize_blockers` 为空，所以总能定稿）。补一条规则：流水线是 `["open"]` 的项目，`open` 定稿时同时标记项目完成（`completed_at`），重新打开时清除——与 `finalize-render` / `reopen` 对出片阶段的处理对称。

`api/animation_stage.animation_stage_of` 对 `open` 返回 `None`：没有渲染任务、`finalize-render`、场景检查。

## 7. 前端

- **创建**：`NewFreeProjectDialog` 的形态选项加「完全自由」；选中后隐藏形态相关控件（背景乐），显示多行"主题"输入框（可选）。选题卡 `CreateProjectDialog` 的 `VideoKindPicker` 自动多出这张卡片。
- **工作台**：`ProjectWorkbenchPage` 在 `stage === 'open'` 时画布只渲染 `FileCanvas`，不出现标签栏；画布顶部是「完全自由」标记与「标记完成 / 重新打开」按钮（调用 §6 的接口）。`StageNav` 不显示阶段条。
- **`FileCanvas` 的 HTML 预览**：`.html`/`.htm` 文件顶部有「预览 / 源码」切换，默认预览。预览用 `<iframe sandbox="allow-scripts">`（不加 `allow-same-origin`）加载原始文件端点，`workspace_changed` 时刷新（同图片的版本号规则）；源码就是现有编辑器。其它阶段的 `FileCanvas` 一并获得这个能力。
  - 现有原始文件端点 `GET /projects/{id}/files/{path:path}` 是路径式 URL，按 `mimetypes` 返回 `text/html`，HTML 里的相对路径（`./scene.js`、`assets/x.png`）自然解析到同一工作区的文件，不需要新端点。`HIDDEN_TOP_DIRS`（`.cache/`、`output/`）下的文件照旧不可访问。
- **文案**：`FileCanvas` 保存 403 的提示改成"不在可写范围内"（不再说"当前阶段"）。
- **标记**：`ProjectCard` 与项目信息显示「完全自由」；阶段筛选认识 `open`。

## 8. 测试

全部纳入 `make check`，测试先行。

- `stages/pipeline`：`OPEN_KIND` 的流水线与 `video_kind`；`open` 搭配形态字段报错；`kind_from_settings` 对 `open` 忽略形态字段。
- `api/projects`、`api/video_kinds`：创建 `open` 项目后工作区只有 `style/**` 与 `project.md`（内容含标题、主题、风格引用）；带 `idea_id` 时主题来自卡片且不写 `notes/`；`open` 带形态字段 422 且无副作用；新卡片出现在列表。
- 快照与文件树：任意深度的 `node_modules/`、`.venv/`、`__pycache__/` 不进清单、回滚不触碰；现有快照测试保持通过。
- `open` 阶段：可写范围（`style/STYLE.md`、`project.md`、`a/b/c.mp4` 可写；`uploads/x`、`.cache/x` 不可写）；工具只有 `tts`；`system_prompt() is None`；`exec_network` 为真。
- `tts`：写入指定路径、默认音色语速、越界路径与非法扩展名报错（TTS 客户端用替身）。
- 运行时：Claude 选项在 `None` 时是 preset、`open` 阶段的工具与禁用名单、`network=True` 时的 sandbox 设置；Codex `None` 时参数里没有指令且不触发 `PROMPT_UPDATE`；OpenAI `None` 时 `instructions is None`；Seatbelt `network=True` 时没有 `deny network*` 但保留三条逃逸规则（含真实执行测试：沙箱内 `curl` 能连上本机回环测试服务器）。现有阶段的对应断言保持不变。
- 完成：`open` 定稿标记项目完成、重新打开清除；多阶段与现有自由项目的完成逻辑不受影响。
- 前端（vitest）：创建对话框的「完全自由」选项与主题框；工作台 `open` 只渲染 `FileCanvas` 与完成按钮；`FileCanvas` 的 HTML 预览/源码切换与 iframe `sandbox` 属性。

**冒烟**（`make smoke`，本机 Claude 订阅登录）：新建 `open` 项目，消息"按 style 做一个 10 秒的标题动画，用 HTML 写，最后用 ffmpeg 导出 `out.mp4`"。验证：

## 9. 文档

- ADR 0031「完全自由模式」：第三种 `mode`；`system_prompt() -> str | None` 表示运行时默认提示词；`exec_network` 放开 Bash 联网而保留读写隔离（相对 ADR 0009/0024 的变化与残余风险）；只给 `tts`。
- `ARCHITECTURE.md`：模块表加 `stages.open`、`stages.common.narration.tts`；更新阶段协议说明。
- `glossary.md`：新增"完全自由模式"，并在"自由模式"条目下注明区别。
- `references/claude-agent-sdk.md`、`references/codex.md`：preset、`allowedDomains` 通配、内置工具禁用名单、Codex 网络开关的实测结论。

## 10. 风险

| 风险 | 应对 |
|---|---|
| Bash 联网后，提示注入可外发工作区内容（读隔离仍挡住仓库、数据目录、凭据目录与其它项目） | 只在 `open` 阶段放开；ADR 写明残余风险；对话里每轮的命令都可见 |
| `allowedDomains` 不支持通配 | 退回常用域名白名单，记进 references |
| preset 下的内置工具（`AskUserQuestion`、计划模式、子 agent 等）在本项目的事件流里没有 UI 对应 | 计划阶段实测内置 CLI 的工具名单，按需 `disallowed_tools`；子 agent（`Task`）若事件流能正常展示就保留 |
| agent 改坏或删掉 `style/`、`project.md` | 每轮快照可回滚；这是负责人选择的"全部可写" |
| 依赖目录撑大快照库 | §4.0：`node_modules`、`.venv`、`__pycache__` 不进快照 |
| 视频等大文件反复生成，快照库增长 | 快照按内容去重；不另做限制，登记技术债观察 |
| HTML 预览 iframe 执行 agent 写的脚本 | `sandbox="allow-scripts"` 不给同源，读不到应用的 cookie 与接口 |
