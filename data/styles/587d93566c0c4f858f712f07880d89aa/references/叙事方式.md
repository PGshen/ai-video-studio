# 叙事方式

## 大致走向

不必拘泥段数，但通常经过这几步：

1. **钩子**：一句说中观众直觉的问话，或一个让人想追问的事实。
2. **一个具体的故事**：有时间、地点、数字的真实事件（或一个可信的典型场景）。让观众跟着故事里的人一起相信那个直觉。
3. **标题出现**：故事把悬念吊起来以后，再亮出标题。
4. **拆穿**：揭示真相，并给这个现象起一个名字。
5. **迁移**：换到观众自己生活里的场景，最好让观众亲自参与一下（小测验、二选一），体会自己也会犯同样的错。
6. **修正**：给出正确的理解方式，用一个具象的比喻把它定格成一句金句。
7. **边界与回收**：说清这个道理在哪里成立、哪里不成立，最后落到观众身上；回到开场的故事或标题，给出新的读法。

原片的例子：1913 年赌场连开 26 次黑 → 人们押红输光 → 「轮盘没有记忆」→ 赌徒谬误 → 答题卡连蒙三个 C → 偏差不会被纠正，只会被稀释 → 什么东西有记忆？你的练习 → 标题反转为「轮盘没有记忆 / 但你的努力有」。

## 字卡的语感

- 短句，一屏一行为主，读得完、记得住。
- 用观众心里的声音说话，多用问句和停顿（「。」「——」「……」）制造节奏。
- 数字、结论、术语这类关键信息，每行最多高亮一处。
- 画面已经演出来的东西，字卡不再重复解释。
- 金句可以脱离底部字卡的位置，单独占一屏。
- 事实要经得起查；引用研究时注明出处。
