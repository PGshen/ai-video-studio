【动画系统：情境驱动·现场推演】

总原则：相机固定。全片围绕一个「情境舞台」推进——开场建立的场景与人物
是后续所有解释的物理容器，机制、证据、代价与迁移都在这块舞台上就地演化。
禁止每镜清空重画；锚点复用是本风格最重要的身份，
而结语镜是全片唯一一次允许清场的镜头。

一、七类身份动作（本风格必须出现）
1. 下注（开场）
   两个中性选项并列建立 → 出现明确的"选哪个"提示 → 画面静止 0.6-1.0 秒。
   此期间禁止任何会暗示答案的高亮、抖动或颜色变化。
2. 抢答反转（开场 8 秒内）
   静止结束后立刻给出定性否定：被推翻的选项在原位转红，
   同时画面下方或中央出现一次短促的否定词（如"当然不对"），
   0.4 秒内完成，不做二次强调、不加震动。反转必须发生在原对象身上。
3. 就地拆解（机制）
   把揭晓后的主体原地展开为机制图：轮廓拉伸成通道、方块分裂成步骤、
   人物退到一侧成为参照。每步先播放可观察变化，变化停稳后再写出概念名。
4. 划叉否定
   否定一个算式或做法时，在其上画一道细斜线，原式保持可读并降为灰紫，
   正确结果在其下方或右侧生长出来，形成"错的还在、对的更亮"的对照。
5. 数字落定（命名代价，全片情绪最高点）
   推导结果沿路径汇聚到画面右侧或中央 → 数字从小放大到最终字号并停住
   → 标签在数字上方淡入 → 画面完全静止 1.5-2 秒，
   期间不允许任何其他元素运动。这是全片唯一一次大幅缩放。
6. 拆弹（边界镜）
   紧接数字落定：其余元素快速退场，只留两个并列对象，
   中间写出"≠"或一道细分隔线，说明模型说的不是什么。
   画面元素数量必须是全片最少的一镜，动作只有一次淡入。
7. 同场景对照（迁移）
   复用开场场景，左右或前后放置"常见做法"与"更有效做法"，
   两条路径同时推进到不同结果，差异用长度/数量/颜色直接可见。
   出路侧的绿色在此首次出现。

二、结语清场（唯一允许的整体重建）
- 所有图表、标注与辅助标签在 0.6-0.9 秒内依次淡出，
  只有贯穿全片的视觉锚点保留在原位并平移到画面中央偏下
- 大字金句分两行写出，第二行字号更大，写入速度比全片其他文字慢
- 锚点上的关键点位逐个点亮（间隔 0.10-0.16 秒），
  点亮顺序对应旁白节奏
- 最后一句旁白结束后，画面保持静止 1-1.5 秒才结束，不做淡出黑场
- 此镜禁止出现新图形、新公式、新颜色

三、动作占空比与时间
- 主要动作 0.55-1.10 秒；微动作 0.20-0.45 秒
- 同类元素错落间隔 0.06-0.16 秒
- 动作前留 0.2-0.4 秒观察起点；结论态留 0.8-1.6 秒读图
- 一个 beat 只承担一个主要语义变化，同时运动的独立对象不超过 3 组
- 全片节奏三次显著变慢：数字落定、拆弹、结语；其余段落保持匀速推进

四、镜头内推进
采用「建立对象 → 发生变化 → 显示结果」。禁止镜头开始时一次性展示全部
元素，也禁止只播进场动画后长时间静止。前一阶段的视觉结果应成为后一阶段
的输入，通过移动、连接、分裂、聚合、替换、对照或强调持续演化。

五、跨镜转场优先级
1. 锚点变形：上一镜的人物、数字、路径或选项框改变形状/位置/标签，
   成为下一镜的解释对象
2. 舞台位移：情境舞台整体平移或缩放到局部特写，再展开新关系
3. 区域承接：淡紫区域底扩张为下一镜的证据区或行动区
4. 整组退场：仅当前后确实没有语义继承时，在 0.5 秒内整体淡出重建
全片不使用黑场和硬切；转场结束后画面必须回到冷白背景。

六、Manim 实现映射
- 线、框、路径：Create；文字与公式：Write
- 同类错落：LaggedStart / AnimationGroup，按空间阅读顺序组织
- 箭头与通道：GrowArrow / Create；粒子或对象传递：MoveAlongPath
- 就地变形：TransformMatchingShapes、TransformMatchingTex、
  ReplacementTransform、Transform
- 数字落定：先 ReplacementTransform 到目标位置，再 animate.scale 到终字号，
  配合 Wait；被划掉的算式用 Line 叠加 + animate.set_color(灰紫)
- 颜色是状态变量：用 animate.set_color / set_fill 改变，
  颜色变化与形状变化尽量放在同一次 play
- 跨镜复用上一镜变量，不重复创建看起来相同的新对象

七、生命周期与防碰撞
每个核心对象走完：建立 → 承载状态/关系 → 得出结论 → 复用变形或完整退场。
过渡时允许短暂穿插，但不超过 0.35 秒。每次 play 结束都检查标题、副题、
数字、主体与标注的包围盒，稳定画面不得有文字压图或元素互相遮挡。
不再使用的辅助线、区域底和标注必须完整退场，禁止降透明后堆在角落。

八、禁止
- 所有镜头统一套用 FadeIn + shift
- 用 zoom / pan 代替对象关系变化；除数字落定外的大幅缩放
- 一次性播完整镜动画后长时间静止
- 每个 beat 重新创建标题、背景和主体
- 在观众下注之前用高亮、放大或颜色暗示正确答案
- 在出路段之前使用绿色
- 结语镜引入新图形、新比喻或新公式
- 用循环、漂浮、呼吸缩放、脉冲或无信息量闪烁填满旁白时长
- 把录屏 UI、通知、字幕、黑柱、黑底插片或尾屏当作转场
- 用章节条、进度条或页码提示叙事位置，段落推进只靠标题和画面变化
