# 歌词类型判定

## 一句话区分

- **意象型**：这句歌词里有能被「看见」的具体事物，闭上眼能想到一个画面。
- **抽象型**：这句歌词讲的是情绪、状态、观念、关系，没有可直接画出的物体。

## 判定步骤（逐句做，再合并成段）

1. 划出句中的**名词和动词**。
2. 有「可画的实物/场景/动作」（雨、站台、灯、河、推开门、点烟）→ 记 **意象**。
3. 只有「抽象名词/形容词」（孤独、永远、意义、遗忘、自由、命运）→ 记 **抽象**。
4. 实物只是比喻的喻体，但喻体本身有画面（「我是一座没人登的山」）→ 记 **意象**，山为主体，情绪由山的处境承载。
5. 实物很泛、只是语气（「在这个世界上」「在时间里」）→ 记 **抽象**。

## 示例

| 歌词 | 类型 | 理由 |
|---|---|---|
| 雨落在旧站台，路灯一盏盏灭 | 意象 | 雨、站台、路灯都可画 |
| 你留下的外套还挂在门后 | 意象 | 外套、门，有物件叙事 |
| 我们终究会被时间遗忘 | 抽象 | 「时间」「遗忘」无具体形象 |
| 一切都没有意义 | 抽象 | 纯观念 |
| 心是一片没有岸的海 | 意象（弱） | 海可画，但是比喻，意象为主、加抽象光场辅助 |

## 段落级归类

- 一段内 ≥ 60% 的句子为意象 → 整段走**意象型**；≥ 60% 为抽象 → 整段走**抽象型**；否则走**混合**。
- **混合段**：意象句用具象镜头，抽象句用「抽象插入镜头」（1~2 秒的几何/光/字），不在同一画面里并置两种语言。
- 副歌常偏抽象（情绪升华），主歌常偏意象（讲故事），这是常见规律，不是规则，以实际歌词为准。

## 全曲标注格式

叙事阶段先产出一张表，后续镜头都引用它：

```
段落 | 歌词摘要 | 类型(意象/抽象/混合) | 核心意象或核心情绪 | 视觉主轴
```

## 整曲基调

整首歌的意象/抽象比例决定整体风格倾向：
- 意象为主（>65%）：整体偏「叙事短片」，抽象镜头只做点缀。
- 抽象为主（>65%）：整体偏「视觉诗/动态海报」，具象物只做锚点。
- 其余：主歌副歌明显分工，转换处用转场承接（见 动画风格.md）。
