# 抽象型叙事蓝图（符号化视觉路线）

适用：歌词讲情绪、状态、观念，没有可直接画的物体。目标是让观众「感到歌词的状态」，不是看到一个故事。

## 原则

1. **先定情绪轴，再选视觉元素**：每段只回答一个问题——这段的情绪是 收缩/扩张、混乱/有序、沉重/轻盈、孤立/聚合 中的哪一种？
2. **一段一种视觉母题**：用少量元素（一个圆、一组线、一团粒子、一行大字）反复变形，不堆新元素。
3. **运动即语义**：情绪靠运动表达，而不是靠图案。
   - 孤独：一个小点在大空白里缓慢漂移
   - 遗忘：文字或粒子逐渐消散、失焦
   - 挣扎：规则网格被一个元素撕开又回弹
   - 时间：均匀重复的线/点匀速流过，某一刻卡顿
4. **关键词上屏**：每段挑 1~3 个最有力的歌词词语做大字排版，作为视觉锚点，不整句铺满。
5. **留白**：画面元素占比不超过 40%，抽象型最怕满。

## 视觉母题库

| 情绪/观念 | 母题 | 变化方式 |
|---|---|---|
| 孤独、疏离 | 单点 + 大面积留白 | 点缓漂，周围有远处微弱的点闪烁 |
| 思念、牵挂 | 两个形体 + 之间的线 | 线被拉长、变细、将断未断 |
| 时间、流逝 | 重复的线 / 点阵 / 同心圆 | 匀速流动，节拍处位移 |
| 迷失、混乱 | 噪点、碎片、错位叠影 | 碎片无序旋转，随后被吸向一点 |
| 释放、觉醒 | 光场 / 渐变面扩张 | 由暗到亮，边缘从硬到软 |
| 遗忘、消逝 | 文字 / 轮廓 | 逐字淡出、模糊、粒子化飘散 |

## 段落结构

| 段落 | 镜头数建议 | 画面任务 |
|---|---|---|
| 前奏 | 1 | 一个母题的最小形态（一个点、一条线），暗底 |
| 主歌 | 每段 2~3 | 母题缓慢生长，关键词淡入 |
| 预副歌 | 2 | 母题增殖或受压，节奏变密 |
| 副歌 | 3~4 | 母题爆发/扩张/聚合，大字关键词卡点 |
| 间奏 | 1~2 | 母题变形为全新形态，纯视觉 |
| 结尾 | 1 | 回到最小形态，但亮度或位置已改变 |

## 单镜头写法（画面描述必须包含）

- **母题与形态**：哪个母题，几个元素，大致位置和尺寸
- **情绪轴**：收缩/扩张等，一个词
- **运动**：方向、速度（慢/中/快）、缓动类型
- **文字**：上屏的关键词，字号层级，位置
- **色**：来自 `配色方案.md` 的色值，通常 2 色 + 1 强调色
