# 动画风格

## 通用

- 画幅 16:9，1920×1080，30fps。
- 节奏跟音乐：镜头切换落在小节线或重拍上；歌词字幕入点比人声早 3~5 帧。
- 缓动：默认 `easeInOutCubic`；情绪爆发用 `easeOutExpo`；漂浮、呼吸用 `sine`。禁止线性运动（除时间流逝类母题）。
- 单镜头时长：主歌 3~6 秒，副歌 1.5~4 秒，前奏/间奏可到 8 秒。
- 每个镜头至少有一处持续的微运动（粒子漂、光呼吸、轻微推近），不能完全静止。

## 意象型

| 项目 | 规范 |
|---|---|
| 镜头运动 | 慢推/慢拉为主，幅度 5%~12%；多层视差（前景、中景、背景速度比约 1.6 : 1 : 0.5） |
| 环境动态 | 雨、烟、灯光呼吸、窗帘、水波，周期 2~4 秒循环 |
| 转场 | 同场景内用叠化（0.5~0.8 秒）；换场景用「物体遮挡切」或「光闪过渡」；避免花哨转场 |
| 副歌 | 景别拉大或主意象状态改变，运动幅度加 1.5 倍 |
| 字幕 | 底部居中，字号 44px，单行 ≤ 16 字，淡入 0.3 秒；不压住视觉焦点 |

## 抽象型

| 项目 | 规范 |
|---|---|
| 母题运动 | 变形与位移为主，不做瞬移；形变用插值，时长 0.8~2 秒 |
| 卡点 | 重拍处元素缩放脉冲 1.0→1.08→1.0（0.2 秒），或位置跳一格 |
| 转场 | 母题直接变形为下一形态（morph）；不用淡入淡出黑场；段落间可用「光场扩张」覆盖 |
| 大字 | 关键词字号 120~200px，居中或黄金分割点；入场逐字 40ms 间隔，出场整体淡出或粒子化 |
| 字幕 | 整句字幕走小号（36px）置于底部或不显示，仅关键词大字上屏 |
| 留白 | 元素占画面不超过 40%，运动区域不贴边 |

## 混合段落的衔接

- 意象 → 抽象：意象主体被「抽走细节」——先模糊，再简化为轮廓，再变成母题几何体。
- 抽象 → 意象：母题几何体逐步长出细节与光源，成为场景中的物体（圆→月亮/灯）。
- 衔接时长 0.8~1.5 秒，落在小节线上。
