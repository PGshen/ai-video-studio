# 意象型叙事蓝图（具象场景路线）

适用：歌词里有可画的事物。目标是让观众「看见歌词里的世界」，并看出歌词没说出口的东西。

## 原则

1. **一个段落一个场景**：同一段歌词发生在同一个空间（站台、房间、街道、海边），镜头在空间里移动，不乱跳。
2. **主意象贯穿**：全曲选 1~2 个主意象（如「雨」「灯」「外套」），每段以不同状态重现，形成回环（第一段亮着，最后一段熄灭）。
3. **转译而非照搬**：不逐字插画。歌词说「想你」，画面可以是「桌上两个杯子，一个已经凉了」。每个镜头要有一处歌词外的细节。
4. **人物克制**：用背影、剪影、局部（手、脚、影子），不画五官表情。
5. **一句歌词至少一个可视焦点**：让观众的视线停在哪里要明确（画面里最亮、最大或最近的那个物体）。

## 段落结构

| 段落 | 镜头数建议 | 画面任务 |
|---|---|---|
| 前奏 | 1~2 | 建立空间和主意象，不出字幕，慢推 |
| 主歌 | 每 2 句歌词 1~2 个镜头 | 铺场景、放物件线索 |
| 预副歌 | 2~3 | 画面收紧：景别变近，物件特写，节奏加快 |
| 副歌 | 3~5 | 空间打开或主意象状态改变（灯亮、雨停、门开），情绪释放 |
| 间奏 | 1~2 | 空镜，主意象独自出现 |
| 结尾 | 1~2 | 回到前奏构图，但有一处不同（呼应） |

## 单镜头写法（画面描述必须包含）

- **景别**：远 / 中 / 近 / 特写
- **主体与位置**：什么物体，在画面的哪里，占多大
- **光与色**：来自 `配色方案.md` 的具体色值和光源方向
- **运动**：推 / 拉 / 横移 / 视差 / 物体自身运动（雨滴、烟、窗帘）
- **歌词外细节**：一句话写明这个镜头额外表达了什么

## 意象转译表（可扩充）

| 歌词里的东西 | 常见转译 |
|---|---|
| 雨 | 玻璃上的水痕、水洼里的倒影、霓虹被雨晕开 |
| 灯 | 一盏灯的明灭对应情绪起落 |
| 门/窗 | 隔开与靠近；开一条缝=希望，关上=结束 |
| 列车/站台 | 离别；窗外景物向后流动=时间 |
| 烟/雾 | 记忆的形状，边缘模糊 |
| 影子 | 缺席的人，比本人更长或更淡 |
