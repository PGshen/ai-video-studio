【视觉系统：概念传记·暖白书卷】

〇、画面规格与画布
横屏 16:9。内容画布暖米白 #FDF8EE，纸面质感；
全片背景不变，禁止黑场与背景切换——情感落差由叙事的语域降档承担，
不靠背景变化。

一、字体（本风格的身份标识）
全片一律衬线体（宋体 / 明朝体系），包括标题、标注与数字，禁止无衬线体入画。
- 术语中英对照：中文衬线 + 英文衬线斜体（如「选择偏倚 Selection Bias」）
- 年代与数据用衬线数字（如「1940s」），带编年书卷感
- 标题可携带编号符号（❶❷❸）与判定符号（✓ ✗）

二、图示词汇表（按论证步骤选型，一步一图示）
把每一步论证翻译成最贴切的图示是本风格不变的身份——观众看到的是
"一页讲义被逐步写满"，而不是某一种固定母题。选型菜单：
- 常识 / 隐喻 → 极简几何隐喻插画（金字塔、直尺、天平、迷雾）
- 学科出身 → 学科符号拼贴环（齿轮环 + 曲线 + 数学符号）
- 场景复现 → 对象示意图 + 散点 / 序列标注（飞机+弹孔、轮盘+连黑序列）
- 实验材料 → 卡片 / 题面 / 问卷
- 排行 / 数据 → 圆角卡表格（斑马纹 + 语义色数字）
- 真相定谳 → 对照双栏面板（彩 vs 灰、✓ vs 红✗）
- 统计概念 → 散点总体 → 箭头 → 子集
- 观众行为 → 简笔火柴人 + 图标 + 箭头场景
- 经验清单 → ✓ 逐条打勾列表
造型语言统一：细线几何简笔、低饱和；同一对象全片造型固定。

三、人物卡制（条件组件，非必选）
仅当叙事采用历史事件 / 经典实验型锚点、且提出者值得出场时使用：
圆角竖卡 + 卡内抽象几何小人（圆头方身、无五官）+ 中文名衬线大字 +
英文名斜体 + 身份标签胶囊（如「统计学家·数学家」「诺贝尔经济学奖得主」）；
双人物两卡并列，中间金色「&」+ 年代标注。
其余锚点类型下署名缩为一行灰色小字或不出现，
禁止为凑传记感硬造人物卡与编年。

四、语义色（含义锁定，不得挪用）
- 砖红 #C0392B：错误、损失、否决划叉
- 青绿 #3DAA8C：成功、正确、存活、勾选
- 芥末金 #E0B84C：焦点圈注、关键箭头、连接符
- 石板蓝 #5B6E9E / 淡蓝 #A9C4E0：中性主体与结构
- 灰 + fill_opacity 0.25-0.35：沉默、被忽略、已消失；
  「灰 + 大红✗」是最重的终局状态

五、对照双栏（核心论证图式，格式锁定）
左右两个圆角面板并置：左栏彩色立起（直觉看到的 / 仍存活的），
右栏灰化 + 大红✗（被忽略的 / 已消失的）；两栏顶部各配短标题。
全片可复用 2-3 次，内容随段更换、格式不变。

六、构图
顶部衬线标题（≤14 字，居中）/ 中部单一主图示 /
底部结论横幅卡（仅收尾章）。负空间 ≥60%。
自检：一章内出现两个互相争夺注意力的主图示，即为不合格构图。
