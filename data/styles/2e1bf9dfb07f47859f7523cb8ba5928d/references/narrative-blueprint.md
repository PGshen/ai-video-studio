【叙事蓝图：概念传记·四问骨架】

〇、选题判定（动笔前判定，决定后文各菜单的取法）
- 概念有著名起源（有名有姓的提出者 / 经典实验 / 历史事件）
  → 显形段可用溯源型锚点
- 概念当场可演（观众 30 秒内能亲历一次）→ 显形段优先当场测试型
- 概念靠数据 / 推演显形（概率、统计规律）→ 显形段用概率推演型
判定一次，全片一致，禁止中途换型。

一、不变内核（风格身份，任何选题不得省略）
全片是给一个概念立传，依次回答四问：
显形（它在哪个场景第一次露出真身）→ 机制（它为什么存在）→
现身（它此刻正如何出现在观众自己的生活里）→ 和解（观众该拿它怎么办）。
并且：
1. 开场 10 秒内制造一次认知张力：让观众意识到"我以为的可能是错的"
2. 概念是唯一主角：命名不晚于全片 1/3 处，命名自带学科出身与分量感
3. 锚点场景论证：全片有一个核心锚点图示承载最主要的推理链，
   推理每前进一步，图示发生且仅发生一次对应变化；
   禁止推理靠旁白空转而画面无事发生
4. 至少一次完整"预期→打破"：直觉答案先在画面上立起来，再被推翻
5. 一次对照双栏定谳：论证关键落点是"直觉看到的 vs 真实发生的"并置面板
6. 第二人称照镜：至少一段用"你"重演观众自己的行为，
   全片第二人称不少于 6 处
7. 一次语域降档 + 对仗金句收束；标题即金句，金句即标题
8. 传记是"讲述"出来的：旁白全文连起来读是一篇连贯的口播散文，
   每章自然承接上一章；禁止把旁白写成画面说明、标题扩写或要点罗列

二、开场钩子菜单（四选一，选定后禁止叠用）
- 打脸式：替观众说出常识判断 + 反问 + 干脆否定。适用：大众有明确错误直觉的题
- 切身下注式：把观众放进两难处境，逼观众先押注。适用：决策类偏差
- 当场测试式：直接给观众出题，让观众 30 秒内亲手掉进陷阱；
  钩子与显形段合一，代入感最强。适用：可交互复现的偏差
- 反常现象式：先摆一个"不该发生却反复发生"的现象。适用：现象类

三、显形段锚点菜单（四选一，决定核心锚点图示）
- 历史事件型：真实历史场景做舞台，锚点图示 = 场景示意图；
  人物卡与编年标注仅在此型且提出者有名有姓时使用
- 经典实验型：复现著名实验，锚点图示 = 实验材料本身；署名可缩为一行小字
- 当场测试型：观众就是被试，锚点图示 = 测试题面；无人物卡
- 概率推演型：数据 / 模拟让概念自己显形，锚点图示 = 序列 / 分布图；无人物卡
共同纪律：锚点内部必须走完一次"预期→打破"；锚点图示建立后跨章继承，
直至推理链终结；每一步推理都要讲透——交代背景、说出直觉、给出反转、
解释机制，禁止把一条完整推理链压缩成一两句话带过。

四、机制段菜单（二选一）
- 权威接力型：第二组研究者给出更深一层解释，仅当确有承接关系的后续研究时使用
- 机制图直击型：跳过人物直接画因果链（大脑 → 直觉捷径 → 偏差），
  配规范术语卡（中英对照）；默认选项
机制段落点固定：对照双栏定谳在此段或显形段末完成。

五、照镜段菜单
- 域按受众选一：投资理财 / 信息流 / 职场复盘 / 消费决策 / 健康习惯，
  选观众最可能昨天刚做过的那一个
- 形式二选一：编号步骤剧（❶❷❸ 逐步重演，末步揭真相）/ 场景重演（单场景小人剧）
- 允许第二次"预期→打破"，但必须换域，不得重复显形段场景

六、降档收束菜单
- 降档领域四选一：爱情关系 / 对自己的苛责 / 遗憾与错过 / 家人
- 降档三标志（齐备才算，全片仅一次）：句子变长且出现比喻 /
  图示退到 1-3 个极简元素 / 标题从名词短语变成叙事句
- 金句规则：对仗句式，回扣锚点意象，冷酷与温情同框

七、章节结构：连续画布五段骨架
物理上没有镜头——全片一张连续暖白画布，零硬切、零转场动画、相机固定。
scenes 数组的一项是一个"章节"：由顶部标题更替 + 中部图示重构界定，
相邻章节至少共享一个视觉锚点。全片 12-14 章，五段按序推进：
- 张力段（1-2 章）：按钩子类型实现；当场测试式可并入显形段
- 显形段（4-6 章，不少于 4 章）：锚点图示入场 → 增量推理（一章一步）→
  直觉反转（立起再划叉/变灰）→ 锚点结论；全段锚点图示连续复用，段内禁止清场
- 机制段（1-2 章）：机制解释 + 规范术语卡 + 对照双栏定谳
- 照镜段（2-3 章）：换域重演观众行为，步骤剧一步一章
- 降档收束段（2-3 章）：极简场景章 + 金句定格章（清场只留对照意象与金句横幅）
章节纪律：锚点图示段内原位继承、不清场；非锚点元素完成使命即退场，
禁止用降透明度代替退场堆在画布上；
每章 description 末尾必须给出两张清单——「退场：××、××」「保留：××（锚点）」，
凡未列入保留清单的上一章元素一律退场；
对照双栏格式固定（左彩右灰、左立右叉），全片可复用 2-3 次；
一章一个主图示，新章主图示享有中部主体区；标题层是全片目录——
名词短语（讲解段）→ 编号短语（照镜段）→ 叙事句（降档段）。

八、节奏与总量（硬性要求）
TTS 常速约 5 字/秒，estimated_duration_seconds = 旁白字数 ÷ 5 +
画面复杂度补偿 0-1.5 秒。成片时长几乎完全由旁白字数决定，
时长不足唯一的解法是扩写内容，禁止用停顿或放慢动画凑时长。
- 成片 150-165 秒 → 旁白总字数 750-850 字，低于 750 字即不合格
- 每章旁白 55-80 字；低于 50 字扩写或与相邻章合并，超过 90 字拆章
- 单章 9-18 秒；金句定格章可 6-9 秒，降档段章节可至 20 秒
- 节奏曲线：快（钩子至命名 ≤20 秒）- 稳（显形 40-55 秒）-
  稳（机制照镜持平）- 缓（降档 25-35 秒，密度骤降即情感信号）-
  定格（金句横幅 3-5 秒）
- 每章 4-7 拍：一句一拍起步，长句在逗号处继续拆拍；单拍 2-4 秒，
  超过 4 秒必须拆拍
- 每拍 visual_action 必须是一个有时间过程的动画（逐个点出、描边生长、
  数值增长、连线延伸、移动变形），禁止"淡入后静置"式一次性动作；
  旁白进行中每 2-3 秒画面必须有可感知的新变化，否则就是在念 PPT

九、旁白措辞：连续讲述体
句与句用时间、因果、转折自然承接（当时 / 于是 / 可是 / 直到），
相邻章节旁白首尾能连读——全部旁白按顺序连读必须是一篇完整流畅的讲述。
句长 10-24 字，允许复句；禁止电报体与名词短语堆叠；
禁止报幕式过渡（"接下来我们看看"），叙事承接词合法；
关键揭晓句 ≤20 字独占一拍；长句与比喻的密集使用只在降档段合法。
旁白语感与每章信息密度以金样本范例为准。

十、自检（逐项执行）
1. 逐章统计旁白字数并求和：低于 750 字 → 回显形段与照镜段扩写推理与细节
2. 总和 ÷ 5 须落在 150-165 秒
3. 章数 12-14；五段俱全且顺序不乱，显形段不少于 4 章
4. 全部旁白连读一遍，读起来像"换了一篇文章"处补承接句
5. 逐拍检查：单拍超过 4 秒、或 visual_action 缺少过程动词（逐个 /
   生长 / 增长 / 延伸 / 变形 / 划过）→ 拆拍或改写

十一、禁止
说教开场、揭晓后自夸、无支撑的形容词、结尾喊口号、方法论清单式收尾、
为凑传记感硬造人物卡与编年、降档超过一次、通篇第三人称冷讲解、
电报体旁白、每章旁白自成孤岛。
