# 配色方案：清新浅色

整体是明亮、留白充足的「白纸 + 卡片」界面：浅色背景，白色圆角卡片承载内容，用低饱和的薄荷、天蓝、珊瑚点缀。

## 基础色

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#F4FAF8` | 极浅薄荷白，全片统一 |
| 背景装饰 | `#DFF3EE` | 左上 / 右下各一个大圆形色块，透明度 60%，不抢内容 |
| 内容卡片 | `#FFFFFF` | 圆角 24px，阴影 `0 8px 24px rgba(36,59,74,0.08)` |
| 主文字 / 公式 | `#243B4A` | 深蓝灰，不用纯黑 |
| 次要文字 / 已完成步骤 | `#243B4A` 透明度 45% | 新一行出现后，上一行降到此透明度 |
| 分割线 / 网格 | `#243B4A` 透明度 10% | |

## 强调色

| 含义 | 色值 | 使用规则 |
|---|---|---|
| 已知 / 关键条件 | 底色 `#FFE9A8`（暖黄） | 作为文字**底色块**使用，文字仍为深蓝灰；同一屏最多 2 处 |
| 所求 / 最终答案 | `#F0605D` 珊瑚红 | 只用于「求」标签与最终答案方框 |
| 推导依据 / 批注 | `#1FAF85` 薄荷绿 | 箭头与小字说明（如「配方」「韦达定理」），对勾也用此色 |
| 辅助线 / 几何构造 | `#4DAEE8` 天蓝 | 虚线，线宽 2px |
| 主图形 / 函数曲线 | `#1E7FBF` 深天蓝 | 线宽 4px |
| 易错点 | `#8C6FE0` 淡紫 | 总结段「易错」卡片，配叉号 |

## 规则

- 一个镜头内强调色不超过 3 种。
- 颜色含义全片固定：黄底=已知，红=所求，绿=依据，天蓝=辅助线，紫=易错。
- 浅底上不要用黄色做文字色，黄色只作底色块或填充。
- 几何图形：主图形线条 `#1E7FBF`、线宽 3px，顶点标签用主文字色；填充区域用主图形色透明度 12%。
- 函数图像：坐标轴 `#243B4A` 透明度 60%、线宽 2px，网格透明度 10%，曲线 `#1E7FBF`、线宽 4px。
- 文字与背景对比度保持在 7:1 以上；强调色小字（32px）不低于 4.5:1，必要时改用加粗。
- 不使用渐变文字、发光、描边等装饰效果。
