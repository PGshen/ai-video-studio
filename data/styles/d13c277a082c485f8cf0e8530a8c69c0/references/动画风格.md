# 动画风格：清新卡片与逐步推导

## 画面与字号

- 画幅 1920×1080，安全边距四周 96px。
- 版式：顶部 80px 为标题条（题号 + 知识点标签，标签为胶囊形，薄荷底 `#DFF3EE`）；主体是一张白色圆角卡片承载推导，宽度约 1500px 居中。
- 题干 / 正文：44px；公式主行：56px；最终答案：72px；批注小字：32px。
- 字体：中文用思源黑体 / 苹方（Regular，标题 Medium），公式用 KaTeX 或 STIX Two Math，行高 1.5。
- 公式左对齐，等号对齐，每行间距 24px；一屏最多 6 行，超出则整体上移或整张卡片换页。

## 通用动效

| 动效 | 参数 |
|---|---|
| 文字 / 公式出现 | 从左到右柔和显现（wipe + 淡入），整行不超过 1.0s |
| 新一行出现 | 淡入 + 上移 12px，300ms，ease-out |
| 旧行弱化 | 透明度降到 45%，300ms |
| 高亮 | 暖黄底色块从左扫到右，400ms，圆角 8px；文字颜色不变 |
| 箭头 + 批注 | 箭头 300ms 描绘，批注 200ms 淡入，批注停留至该步结束 |
| 卡片换页 | 旧卡片向左滑出并淡出，新卡片从右滑入，500ms，ease-in-out |
| 答案方框 | 珊瑚红圆角方框 600ms 描绘，描完后轻微放大 1.04 再回弹 |
| 对勾 / 叉号 | 描绘 300ms，带一次轻微弹跳 |

## 几何与函数

- 图形先画主体（线条描绘 0.8–1.5s），再加点标签，最后加辅助线；每类元素分别动画，不同时出现。
- 点标签用大写字母，28px，贴在顶点外侧 12px。
- 角度用圆弧 + 度数标注；相等线段 / 相等角用相同数量的短划 / 弧线标记。
- 函数图像沿 x 方向描绘，时长 1.5s；关键点（交点、极值点）用 12px 实心圆点 + 外圈脉冲一次。
- 平移、对称等变换用位移补间 800ms，ease-in-out，保留原图形 30% 透明度的残影。

## 节奏

- 每个镜头 6–15 秒；推导镜头不超过 15 秒。
- 动画与旁白同步：画面元素先于对应旁白 0.2s 出现。
- 镜头之间用卡片滑动或 400ms 交叉淡化，不使用旋转、翻页、缩放爆炸等花哨转场。
- 配乐用轻快的钢琴 / 木吉他 / 环境氛围，音量不超过人声的 15%，不用强节拍。
