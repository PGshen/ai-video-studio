# 手绘信息卡科普

**米白纸面上的手绘插画，配一张珊瑚红信息卡和一条步骤进度条，用一条问题链把一个反常识的道理从现象讲到意义。**

## 叙事

- **问题链**：每一章用一个问题收尾，下一章第一句回答它。观众始终带着一个问题往下看。
- 大致走向：几个日常现象引起共鸣 → 用一个摸得着的例子讲清底层规律 → 推广到观众身边 → 给出反方向的力量，把“难”重新定义 → 几条可以照着做的方法 → 从个人拉到更大的尺度，给观众一个积极的自我定义。
- **先例子，后概念**：概念只是给已经看懂的现象起个名字。
- **一句一个画面**：写不出画面的句子就删掉。“A 要……，B 只要……”这种对仗句很好用。
- 情绪：共鸣 → 恍然 → 释然 → 振奋。讲完消极的一面，马上给出重新定义，不停在悲观里。
- 数字和引语要有出处；比喻不说成“科学证明”。

## 视觉

- **固定版式，只变内容**：竖屏自上而下依次是标题、副标题、插画区、信息卡、字幕、步骤条，位置全片不变；变化的只有插画和卡片内容，观众不用每次重新找重点。
- **手绘质感**：插画和边框是带轻微抖动的手绘线（抖动固定，不逐帧跳），圆角端点；文字保持清晰，不抖动；纸面有细噪点，不用渐变和投影。
- **一种强调色**：珊瑚红（约 `#e8656f`）是唯一的重点色，用于标题、大数字、高亮词、已完成的步骤；一个画面里只有一处珊瑚红。墨色（约 `#2b2a2e`）描边，米白（约 `#f6f5f1`）作底；深红表示崩塌和出错，绿表示生长和修复，金表示能量。
- **用形状讲数字**：“20 年 vs 5 分钟”画成两条进度条；插画里的标签写结论，不写描述。
- **前后呼应**：同一个物件在开头和结尾以不同状态出现（洗乱的牌 → 排整齐的牌）。
- 字体活泼圆润，有手写感。

## 动画

- 画面跟着旁白走：句内的动作卡在关键词说出的时刻。
- 插画之间交叉淡化；信息卡本身不动，只换内容；进入新章节时，步骤条打勾并点亮下一步。
- 常用的动效表达：慢慢积累再瞬间崩塌（建立难、破坏易）、有序变无序、快速扩散对缓慢恢复、实时计数让数字有分量、弹出加放射线标出重点时刻。
- 一句话里最多一个大动作；画面保持轻微的持续微动。
