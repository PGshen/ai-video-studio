# 手绘信息卡科普视频

**一句话定义：米白纸面上的手绘插画，配一张珊瑚红信息卡和一条步骤进度条，用旁白和字幕把一个反常识的道理从现象一路讲到意义。**

整理自《变好难 · 变差易》（熵增版，竖屏 1080×1920，2 分 53 秒），视觉语言参考一支 30 秒的手绘鸡尾酒教程短片。

## 基本参数

| 维度 | 取值 |
| --- | --- |
| 适用选题 | 一个观点讲透的知识科普：物理、心理、经济、人生观点；能拆成“现象 → 原理 → 延伸 → 转折 → 行动”的问题链 |
| 时长 | 2–3 分钟，30–40 句旁白 |
| 画幅 | 竖屏 1080×1920（主），方屏 1080×1080（备选） |
| 帧率 | 30 fps |
| 声音 | TTS 旁白 + 字幕，默认不加背景音乐 |
| 情绪基调 | 先共鸣，再解释，最后积极收尾，不渲染悲观 |

**画得出来**：物件（扑克牌、灯泡、书）、进度条对比、网络图、仪表盘、曲线图、小场景（城市、河流、树）、计数与数字对比、有序/无序的粒子变化。每句旁白都要能落成一个这样的插画动作；写实人物、复杂真实场景、照片类素材画不出来。
