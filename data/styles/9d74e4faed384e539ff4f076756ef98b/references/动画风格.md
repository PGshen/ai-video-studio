# 动画风格

动画由旁白驱动：每句旁白的真实时长决定这一句的画面时长，句内动作按时长的百分比安排，换配音不用重新调动画。

## 时间轴

- **起始**：前 3 秒留给标题开场（0.15–1.25 秒逐字打出，2.1–2.9 秒从中央缩到顶部），第一句旁白从 3.0 秒开始。
- **每句时长** = 旁白音频时长（已裁掉首尾静音）+ 0.3 秒停顿 + 可选的额外留白（动作多的句子加 0.15–0.4 秒）。
- **章节间隔**：每章开头前多留 0.6 秒，给步骤条打勾和插画切换。
- **结尾**：最后一句之后停留 4 秒。
- **句内动作**用百分比定位：例如“洗一次，就再也洗不回去了”在句长 42% 处开始洗牌，对上“洗一次”这几个字。

## 缓动

| 名称 | 公式 | 用在 | 常用时长 |
| --- | --- | --- | --- |
| easeOutCubic | 1 − (1 − x)³ | 淡入、字幕上浮、建筑升起 | 0.2–0.6 秒 |
| easeInOutCubic | 三次曲线两端缓 | 位移、洗牌、指针、曲线绘制 | 0.5–1.0 秒 |
| easeOutBack | 过冲系数 2.2 | 弹出：卡片、图标、花瓣、结尾大字 | 0.35–0.5 秒 |
| 线性 / 平方 | x、x² | 加速坠落（球滚下坡、积木掉落） | 0.4–0.6 秒 |
| 阻尼振荡 | e^(−4t)·cos(9t) | 天平摇摆等物理反馈 | 约 1 秒 |

## 入场与转场

- **插画切换**：前一张在结束前 0.3 秒淡出，后一张提前 0.2 秒用 0.35 秒淡入，两者交叉，不用滑入或全屏转场。
- **信息卡换内容**：卡片本身不动，内容上浮 12 px + 淡入（0.25 秒）。
- **字幕**：每句上浮 8 px + 淡入（0.2 秒），与旁白同时开始。
- **步骤条**：新章节开始时，上一步弹出打勾，连线用 0.5 秒填成珊瑚红，当前步弹一下。
- **元素序列入场**：同类元素错开 0.06–0.15 秒依次弹出（发牌、建筑升起、齿轮、柱子）。

## 常用动效模式

| 模式 | 表达的意思 | 本片用例 |
| --- | --- | --- |
| 慢慢积累→瞬间崩塌 | 建立难、破坏易 | 书架、习惯进度条、推石上坡、声誉进度条 |
| 有序→无序 | 熵增 | 洗牌、粒子扩散、城市衰败（窗灭、裂缝、藤蔓） |
| 无序→有序 | 逆熵 | 树把散落的点收拢成树冠、点汇成圆环、扑克牌重新排整齐 |
| 快速扩散 vs 缓慢恢复 | 不对称 | 谣言网络 0.7 秒全红，澄清每圈要 1.6 秒 |
| 连锁反应 | 复杂系统的脆弱 | 网络一点变红，每 0.22 秒传一跳 |
| 实时计数 | 让数字有重量 | “坚持了 N 天”、“20 年”、复利倍数和天数进度条 |
| 弹出 + 放射线 | 重点时刻 | 灯泡亮起、“负熵”印章、旗帜、结尾大字 |
| 持续微动 | 画面不死板 | 水流平移、鱼摆尾、太阳旋转、心跳、点轻微晃动 |

## 节奏

- 平均每 4.7 秒换一张插画，每 3–5 秒换一次卡片内容。
- 一句里至多一个“大动作”（崩塌、洗牌、扩散），其余是准备和余韵。
- 情绪转折的句子（问句、升华句）多留 0.4–0.8 秒。
