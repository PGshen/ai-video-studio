# 配色与字体

## 配色

| Token | 色值 | 用途 |
| --- | --- | --- |
| bg | #f6f5f1 | 米白纸面底色，叠加一层 9% 不透明度的纸张噪点 |
| ink | #2b2a2e | 所有描边、正文字 |
| coral | #e8656f | 唯一的强调色：标题、大数字、高亮词、已完成步骤 |
| deep | #a63745 | 标题投影、“变差/出错”状态 |
| pink | #f5d0d3 | 信息卡阴影、柔和填充 |
| gold | #f4c45a | 能量、阳光、亮着的窗 |
| lit | #ffd86b | 发光物体（灯泡） |
| green | #8cc49a | 植物、“澄清/恢复” |
| glass | #e4f0f5 | 水、玻璃 |
| grey | #c4bfb8 | 未激活步骤、辅助线 |
| text | #6d6863 | 次要文字、副标题 |

语义固定：珊瑚红 = 重点/好的方向，深红 = 崩塌/出错，绿 = 生长/修复，金 = 能量。一个画面里只让一个东西用珊瑚红。

## 字体

| 用途 | 字体 | 字号（竖屏实际显示） |
| --- | --- | --- |
| 主标题、结尾大字、卡片标题 | 站酷庆科黄油体 ZCOOL QingKe HuangYou | 标题 94、结尾 148、卡片标题 55 |
| 字幕、标签、副标题 | 站酷快乐体 ZCOOL KuaiLe | 字幕 42、插画标签 ≈45 |
| 大数字、英文 | Luckiest Guy | 卡片大字 104 |
| 步骤编号 | Patrick Hand | 28 |

中英文混排用字体栈 `LG, QK`：数字和字母走 Luckiest Guy，中文自动回落到黄油体。全部为 Google Fonts 开源字体（OFL / Apache）。
