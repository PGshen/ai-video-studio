# 制作流程与技术实现

整支片子是一个由时间驱动的 SVG 页面：`render(t)` 画出第 t 秒的画面，逐帧截图后合成视频，写一次代码就能反复改稿重渲。

声音：TTS 旁白 + 字幕，默认不加背景音乐。

## 流程

1. **定稿**：按叙事结构写旁白，每句标出高亮词 `[…]` 和上标 `^67`。
2. **合成旁白**：火山引擎 TTS（volcengine-tts），音色 xiaoxinjiejie，语速 1.1，逐句合成。数字在 TTS 文本里改成口语。
3. **裁静音、取时长**：ffmpeg silenceremove 去掉每句首尾约 0.4 秒的静音，写入 `durations.js`。
4. **生成时间轴**：页面读取时长，算出每句的起止时间 `T[id]`，所有动画都引用它。
5. **抽帧预览**：按句子起点 + 偏移渲染关键帧（如 `e2+5`），拼成对照图检查排版。
6. **逐帧渲染**：Playwright 无头 Chromium 以 30 fps 截图，管道送入 ffmpeg（libx264，CRF 18）。竖屏约 5200 帧，约 5 分钟。
7. **合成音轨**：按时间轴摆放旁白，响度统一到 −14 LUFS（loudnorm），封装 AAC 192k。
8. **导出字幕**：从同一份时间轴生成 SRT。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| index.html | 1080×1920 的 SVG 画布、字体声明 |
| main.js | 工具函数、旁白列表 CAP、插画 ill()、卡片状态 cs()、render(t) |
| tts2/*.mp3, tts2/trim/*.wav | 原始和裁剪后的逐句旁白 |
| tts2/durations.js | 每句旁白时长 |
| render.py | 抽帧（stills）与整片渲染（video） |
| fonts/ | 4 个开源字体文件 |
| timeline.json, subtitles.srt, voice.wav | 导出的时间轴、字幕、旁白音轨 |
